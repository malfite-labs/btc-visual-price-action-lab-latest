# BTC Paper Lab V3.1 量化绩效指标计算规范

> 引擎实现：`scripts/research_v3_engine.py`（`CALCULATION_VERSION = "RESEARCH-METRICS-V3.0.0"`）

---

## 1. 核心绩效指标公式与边界处理

| 指标 | 计算公式 / 统计口径 | 边界与防错规则 |
|---|---|---|
| **区间期初权益** | `initial_capital + sum(exit_time < start_dt 的已闭合净盈亏)` | 指定研究区间时使用区间期初权益，**不始终使用建账时的 10,000** |
| **区间净盈亏** | `interval_end_equity - interval_start_equity` | 存在外部现金流/重置时单独剥离，不计为策略盈利 |
| **区间净收益率 (%)** | `(interval_end_equity - interval_start_equity) / interval_start_equity × 100%` | 期初权益 `<= 0` 时返回 `None`（显示 `—`） |
| **完整闭合交易数** | 具备唯一开平仓配对证据、数量方向一致、有效价格费用的完整生命周期笔数 | 在途未平仓位单列 `active_open_count`，不误报为数据错误；缺少闭合证据的记录绝不计数 |
| **胜率 (%)** | `净盈利闭合交易数 ÷ 有效完整闭合交易总数 × 100%` | 盈亏持平（`net_pnl == 0`）计入分母；无闭合交易时返回 `None`（显示 `—`） |
| **盈利因子 (PF)** | `sum(net_pnl > 0) ÷ abs(sum(net_pnl < 0))` | 无亏损交易且有盈利时返回 `None` + 展示 `∞（无亏损交易）`，**严禁返回虚假的 999**；无交易显示 `—` |
| **最大回撤** | 逐权益观测点计算 `peak = max(peak, eq)`、`dd_amt = peak - eq`、`dd_pct = dd_amt / peak × 100%`，取最大值 | 少于 2 个有效权益观测点返回 `None`（样本不足）；同步记录 `dd_start`、`dd_trough`、`dd_recovery` 与 `in_drawdown` |
| **平均每笔净盈亏** | `sum(net_pnl) ÷ 有效完整闭合交易总数` | 无闭合交易返回 `None` |
| **手续费与滑点** | 优先读取底层已审计 `net_pnl`（A/B/C/E `POSITION_CLOSED`、D/G 显式净盈亏）；策略池按 `gross - open_fee - close_fee` 计算 | **严禁重复扣减手续费**；成交价已含不利滑点，滑点仅作参考列展示不二次扣除 |

## 2. 归因分析与跨版本口径

- **多空方向分析**：按 `LONG` / `SHORT` 分别统计闭合笔数、胜率、净盈亏、平均盈亏、盈利因子。
- **退出原因分析**：统一归一为 `止盈` / `止损` / `策略信号退出` / `时间退出` / `其他退出` / `未知原因`。
- **开仓时段与星期分析**：统一转换至 **北京时间（UTC+8）**，按 4 小时时段桶与周一至周日统计。
- **持仓时长分析**：按 `1小时以内` / `1至4小时` / `4至12小时` / `12至24小时` / `24小时以上` 分组。
- **策略版本归属**：按 `opening_strategy_version` 归属历史绩效，严禁将旧版本历史成交重新归属至最新版。
- **多策略对比可比性**：支持共同有效区间对齐与归一化曲线（基准 = 100 / 收益率 = 0%）；不同 `capital_model` 强制弹出不可直接排名提示。
- **高级年化指标预留**：首期不强制计算夏普/索提诺/卡玛比率，待高频连续权益采样与无风险利率口径冻结后通过同一指标模块平滑扩展。
