# V1.0.4 用户批准的研究运行参数

本文件是 V1.0.3 原有工程规格的增量修订；原始文档、成交、账本流水和既有验收报告保留。用户于本轮批准以下配置：

| 项目 | 冻结值 |
|---|---|
| 行情 | Alpaca BTC/USD 现货，内部 USD 研究账户 |
| 参考 | 币安 BTCUSDT U 本位永续普通用户；仅为用户指定的研究参考 |
| 模拟成交 | 市价，盘口可用深度和价格保护 |
| 开仓/平仓 taker 手续费 | 各次成交名义价值 × 0.0005；记账时向上取整至美分 |
| maker 参考费率 | 0.0002；不用于市价成交 |
| 不利滑点 | 每次成交 0.0002，叠加在对应买一/卖一或盘口 VWAP 之后，价格按不利方向和模拟 tick 取整 |
| 杠杆 / 计划风险 | 1 倍 / 当前权益最多 2%，按风险、资金、名义、精度及流动性约束取最小数量，并对实际模拟价格与手续费取整再次校验 |
| 报价与盘口最大年龄 | 60,000ms，边界包含；不降低供方时间戳、断线或周期截止校验 |
| 资金费 | 暂不计入 |

多头开仓买入使用卖侧报价、多头平仓卖出使用买侧报价；空头开仓卖出使用买侧报价、空头平仓买入使用卖侧报价。盘口价差和不利滑点均在成交价内，账本不再单独扣取滑点。真实 Alpaca 费用、币安账户费率及实际执行质量并未由该研究模型证明。

新成交逐笔保存成本模型、费率、滑点及资金费状态；升级前的成交保留原值，成本版本留空并标识为旧记录，不补写历史费率。运行期间风险拒绝、行情不可用与周期拒绝应保留状态或审计证据。有效且更新的报价优先于决策前报价；行情更新失败、断流、失效或决策逾期时拒绝新开仓。

本轮只进行隔离测试与配置冻结，不启动正式无人值守模拟盘。未来受控观察期间的模拟交易与工程故障记录不是正式策略盈利验证；不要求事先完成独立的长期稳定性实验。
