## 2. 数据和一致性约束

- 所有金额、价格、数量用十进制定点数；所有对象含 schema_version。
- 每条持久化事件包含 UTC occurred_at、observed_at、monotonic sequence_no、event_id、correlation_id、payload_hash、schema_version。sequence_no 在单一账本事件流内严格递增且唯一；排序以 sequence_no 为准，时间戳只用于展示与诊断。
- 每个代理每个 candle_close_utc + active_version_id 唯一决策槽；决策幂等键：`decision:{agent_id}:{bar_close_utc}:{strategy_version_id}`。
- 交易意图唯一键：`intent:{decision_id}:{action_epoch}`；账户仅一个未平仓仓位约束；执行动作绑定 account_state_version 和 quote_id。
- 成交唯一键：`fill:{intent_id}:{fill_leg}`；账本唯一键：`ledger:{source_event_id}:{event_type}:{leg}`。重复投递返回已持久化结果，不重复产生副作用。
- 一个成交、相应费用/资金流水、仓位更新及 trade 汇总在一个本地数据库事务中提交；事务使用唯一约束和账户版本比较更新。任何约束冲突均回滚，并由状态机读取已有事实决定返回 duplicate、conflict 或 locked，不进行盲重试。
- 事件重放只构建状态，不重发外部模型任务、不重放成交副作用。模型任务重启后标记为未知/过期，旧回复不得成为新周期命令。

## 3. 视觉决策和 API 数据链

每根已收盘 15m K 线确认后，M03 生成唯一 VisualSnapshot；A/B/C 图像字节相同，SHA-256、288/96 candle ids、边界和图像生成时间随决策证据保存。代理上下文互相隔离。模型输出按版本化结构解析；动作只有 WAIT、OPEN_LONG、OPEN_SHORT、CLOSE_POSITION。结构非法、止损方向错误、账户版本失配、行情过期或超截止一律拒绝并保存原因。

每次模型调用保存 provider、model/version 标识、请求 id、输入图像 hash、MD hash、prompt/schema 版本、请求/完成时间、attempt、token/费用（服务提供时）、原始响应内容 hash、解析结果、超时/错误类别。原始敏感上下文仅存本地；不得将 API key 写入证据。

模型超时为决策周期开启的硬截止：deadline = min(start + CFG-05.timeout, next_bar_close - CFG-05.safety_margin)。重试只能占用该次任务的预算和剩余截止时间；达到截止立即 EXPIRED。CFG-05 数值未冻结时，模型不能发出可执行新开仓决策。

## 4. 阶段计划与交付门

| 阶段 | 内容 | 依赖 | 门槛/交付 |
|---|---|---|---|
| P0 | 本规格落版、需求追溯、独立目录和安全封锁设计、配置核验、API/事件合同与测试计划 | 无 | 冻结所有影响 P1–P3 的参数或保持明确禁用；确认只访问公开行情；明确不含交易签名能力。交付基线、配置清单、接口核验计划、测试合同。 |
| P1 | M01–M03 行情和视觉图 | P0 | 15m 收盘事件、回补、恢复、288+96 图像 hash 一致、报价/资金费事件 schema。缺口或未收盘泄漏即停。 |
| P2 | M04–M07 MD、真实视觉接口和决策验证 | P1 | A/B/C 独立上下文；结构化结果和真实多模态证据；C 核心只读契约。参数预算/超时/供应商版本有配置。 |
| P3 | M08–M10 风险执行、账本和进化基础 | P1–P2 | 公式一致，L1 容量约束，事务/幂等，止损待处理恢复，资金费可复算。先用确定性合成事件。 |
| P4 | M11–M12 工作台 | P1–P3 | 成交主图、API 曲线/MD/版本追溯、各运行状态准确；固定账本样本逐条校验。前端阻断等级统一称 UI-P0，避免与工程阶段 P0 混淆。 |
| P5 | M10 影子研究与进化 UI | P2–P4 | 50 笔批次、排队、7/14/21/30 检查、指标公式、待升级自然平仓切换。 |
| P6 | 综合恢复、自动化验收、有限真实行情/视觉观察（另行授权后） | P0–P5 | 全验收矩阵证据；合成/真实公开行情/真实模型明确分类；失败不宣称通过。 |

## 5. P2 项目化分配

| P2 来源 | 处理阶段 | 处理方式 |
|---|---|---|
| 图表标记的重叠、聚合阈值和可视回归细节 | P4 | 冻结坐标锚定与聚合阈值配置；用固定 fills fixture 做截图/DOM 锚点回归，不改变标记来源或配色。 |
