## 1. 产品目标与边界

提供一个只读公开行情驱动的 BTCUSDT U 本位永续合约视觉价格行为研究工作台。A、B、C 三个相互隔离的视觉 AI，在每根已收盘 15 分钟 K 线后，观察同一份纯裸 K 线图，并在各自独立虚拟账户中形成决策和模拟账本。系统不提供真实下单能力；盈利不是基础闭环验收条件。

### 冻结要求

| ID | 冻结需求 |
|---|---|
| PR-001 | 系统固定三名独立视觉 AI：A 趋势结构，B 关键位反转，C 用户自定义理念。不得跨代理共享私有记忆、策略文本、账户或影子账本。 |
| PR-002 | 决策周期为 BTCUSDT U 本位永续 15 分钟；只使用已收盘 K 线；视觉输入为最近 72 小时 288 根全局裸 K 线及最近 24 小时 96 根局部放大视图，局部图必须来自同一批历史数据。 |
| PR-003 | 三个 AI 对同一决策时点使用字节完全一致的输入图像（SHA-256 相同）；各自附加独立 MD、记忆和账户状态。不得加入技术指标、未来数据、交易答案或以像素价格模拟成交。 |
| PR-004 | 三个 AI 各有独立虚拟账户，起始权益各 10,000 USDT；单仓、不可加仓，先平后反手。任何真实交易、交易所测试网下单、签名密钥、入金或真实账户连接均不属于 V1。 |
| PR-005 | 名义敞口上限为账户当前权益的 1 倍（且不超过可用保证金）；计划止损风险预算不超过该账户决策时权益的 2%，必须将配置的手续费和滑点成本纳入计算。以盘口可成交量、保证金和交易数量规则继续约束；数量按 step 向下舍入并重新校验，不满足时拒单。详见风险规范。 |
| PR-006 | 止损由标记价格触发；标记价格只判定是否触发，退出模拟成交使用触发后可得的对手方买一/卖一报价并应用配置滑点。报价无效时不造成交，持久化待退出状态并报告保护状态不确定。 |
| PR-007 | 主工作台在同一张 K 线图显示实际模拟成交：A 红 #E45454、B 绿 #16A777、C 橙 #ED992F。标记必须来自成交记录并绑定 fill_id；未成交建议不可显示为实际成交。 |
| PR-008 | 系统完整记录市场、图像、决策、版本、订单意图、成交、费用、资金费、账户事件及审计证据；账本事件追加且幂等，时间统一 UTC 并区分事件时间与接收时间。 |
| PR-009 | 每个代理每累计 50 笔完整往返交易形成一个复盘批次；候选槽被占用时批次排队，每代理最多一名影子候选。拒绝/未成交决策不计入完整交易。 |
| PR-010 | 影子对照与候选有共同起点和独立账户/记忆/仓位，使用相同未来行情图像、模型版本、费用、风险和执行规则。第 7、14、21、30 天检查；每次评估要求双方各至少 20 笔完整交易。 |
| PR-011 | 只有候选同期净收益更高、平均盈亏比更高，且最大回撤同时满足不超过对照的 1.1 倍和不超过对照 2 个百分点，才可进入自动升级待生效状态。30 天未通过或不可判定则淘汰；不得延长观察期。 |
| PR-012 | 升级不得迁移或改写历史；现役有仓时必须等自然平仓后，在下一次合格决策前切换新版本。 |
| PR-013 | 所有策略版本只增不改；C 的用户核心理念只读保护，候选只能修改明确可进化部分。C 原稿未提供时，只能验证导入隔离，不得编造或宣称 C 策略通过行为验收。 |
| PR-014 | 前端展示行情、AI/账本/保护状态必须反映后端事实；网络或模型降级时禁止新开仓，止损服务与视觉模型隔离。 |
| PR-015 | 工程验收必须区分合成事件、固定行情样本、真实公开行情和真实视觉模型调用；任何合成样本不得冒称真实市场成绩。 |

### 用户明确确认且纳入本次基线的决策

- 保留三名独立视觉 AI、15 分钟 BTC 裸 K 线、3 天全局 + 1 天局部图、三份独立模拟账户。
- 保留 1 倍杠杆上限、2% 计划风险、A/B/C 红绿橙成交标记、50 笔复盘和影子进化。
- 影子检查固定在第 7/14/21/30 天；双方各至少 20 笔完整交易；符合既定收益、盈亏比和回撤门槛才自动升级，最长 30 天，旧仓自然平仓后切换。
- 本轮是规格修订与静态审查，不授权代码、脚手架、依赖、账户、模型调用、模拟交易或部署。

## 2. 明确非目标

真实交易或交易所测试网下单；高周期作为 AI 输入；MA/MACD/RSI/成交量等指标参与决策；强制下单凑样本；跨策略共享记忆或资金；加仓；以历史回填伪造成交；将策略文本改写宣称为盈利改善；在本轮运行系统或调用收费模型。
