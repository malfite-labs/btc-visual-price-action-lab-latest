# 本机纸盘单策略控制实施计划

目标：A/B/C/E 可独立暂停及恢复；暂停先封闭新开仓，再以现有撮合、报价和成本规则平掉正式与影子持仓。系统仅服务本机纸盘，不接真实交易。

1. 先写状态机测试：启用、暂停请求持久化、正式与影子平仓、缺库/陈旧报价/执行失败保持阻断、重启恢复、重复请求幂等；在测试临时账本运行，不触碰现有数据库。
2. 为新开仓与暂停使用同一可重入串行化边界，覆盖 ABC 同步周期、E 正式及影子线程；确认暂停提交后任何并发开仓无法通过。保留原有止损、目标及恢复。
3. 持久化每策略状态与每账户处理结果；事务先写禁止新开仓，再处理现有仓位。每次操作验证身份、订单版本、报价来源和时效，并使用既有 Ledger 成交和费用。成功需各账户明确 FLAT；影子不存在/不可核实则显示未完成，不能创建空库冒充。
4. 以本机受限 API 暴露读取、暂停、恢复，明确恢复不得跳过未完成平仓。桌面每行按钮显示真实状态，并提示强制模拟平仓；禁止仅凭本地按钮状态声称成功。
5. 定向测试覆盖停仓与开仓/止损并发、失败注入、进程重启、重复请求、影子缺失/异常、不同策略隔离、E 正式/影子同步；回归原有执行测试。隔离测试全通过后检查实际账户、备份账本、受控部署，验证真实 API 和自然周期；不得因测试需要强制实际持仓成交。

部署边界：本机 ABC 影子库目前缺失，不能声称所有策略的暂停已完整成功；若仍缺失，界面应报告影子不可用并维持禁止开仓。真实盘需要独立交易所适配、权限、安全设计和专项验收，不能直接沿用纸盘实现。
