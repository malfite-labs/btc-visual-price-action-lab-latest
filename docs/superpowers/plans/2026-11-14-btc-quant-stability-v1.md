# BTC量化系统稳定性升级 V1.0 实施计划

**目标：** 在保护现有实盘纸盘账本和持仓的前提下，先重建ABC影子账本并恢复自然周期，再交付统一策略生命周期、自动备份和运维状态。

**架构：** P0使用当前 `Ledger` 与 `forward_v26` 表结构，新建标记为 `REBUILT_NEW_EPOCH` 的空历史纪元；P1以自动发现的SQLite清单和Online Backup API建立可验证快照；P2复用声明式 `StrategyPool` 的版本/验证/启停接口；P3仅在现有桌面控制台增加真实健康与备份状态。

**技术栈：** Python、SQLite Online Backup API、FastAPI、现有Tk/HTTP桌面控制台、PowerShell恢复入口。

**全局约束：** 不重置正式账户、不复制正式持仓进影子账本、不伪造丢失历史、影子复盘阈值40、所有新策略默认禁用、不增加Alpaca连接、不启用Watchdog。

**重点风险检查：** 活动影子账本路径判断错误；初始化覆盖现有文件；以50笔阈值误触发；备份漏掉实际活动账本；轮询任务阻塞止损；启停状态被误报成运行中；恢复重启后PA08被缺口清空。
