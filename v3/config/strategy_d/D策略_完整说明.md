# D策略：15分钟急跌后底部反转研究方案

版本：1.0.0｜研究日期：2026-11-05｜市场：加密资产 USDT 线性永续合约｜方向：只做多。

这是可供实现和回测的策略规格，不是已验证盈利的交易系统。随附 JSON 是自定义配置与规则说明，不是任何交易平台的可直接导入格式。本次没有历史行情、模型训练或收益回测，所有数值都是研究初值。交易所、账户费率和合约细则仍须指定。

## 1. 需求理解与方案选择

目标是在15分钟K线出现明显下跌后，识别第一次有证据的局部反转，避免等行情大幅上涨后反复提示开多。研究 BTCUSDT、ETHUSDT 永续作为起点，不声称其他币种通用。

截图可观察到：左侧横盘后逐步下行，中部跌幅加速，低点附近出现下影与反弹，随后连续向上并出现密集标记。红箭头位于下跌段附近，并不等于可实时确认的最低点。图中没有可读价格轴、时间、成交量和指标定义，无法证明放量、背离、实际收益，无法逐根验证本策略会在哪根触发。原有B/C等标记只视为图像内容，不继承其交易逻辑。

考虑三条路径：纯视觉模型直接买卖，灵活但难校准和复现；纯OHLCV规则，透明但形态表达有限；价格规则加视觉辅助，能保留基准并检验视觉是否带来增益。本方案采用第三条研究路径，先交付默认启用的 D-R 规则基线，D-V 视觉过滤作为默认关闭的实验分支。两者使用相同入场、止损和成本模型。

## 2. 前沿研究如何落到本策略

截至研究日检索并核对的代表性来源，不等于穷尽所有最新成果：

| 来源 | 可借鉴之处 | 不能据此推断 |
|---|---|---|
| [FinChart-Bench，2025-07-20](https://arxiv.org/abs/2507.14823) | 对金融图表理解做单独评测，强调空间推理局限 | 读图得分不等于交易收益 |
| [多尺度K线VLM评测，2026-04-14](https://arxiv.org/abs/2604.12659) | 使用多尺度视图，并与XGBoost等数值基线比较；报告预测偏差 | 多周期输入不能保证识别底部 |
| [QuantHarness v4，2026-07-27](https://arxiv.org/abs/2509.09995v4) | 将指标、形态、趋势和风险拆开，形成可追溯决策 | 论文摘要中的1小时/4小时实验不能迁移为15分钟有效性 |
| [E2A-Bench，2026-09-13](https://arxiv.org/abs/2609.14302) | 检查证据、理由、置信度和动作是否一致，关注买卖偏差 | 证据可靠性指标不是实现收益 |

由这些研究得到的设计判断是：图像用于辅助识别结构，价格与风险必须由数值验证；不让大模型从像素读取精确下单价，不把模型自报“90%信心”当作胜率。这是本方案推论，不是论文证明的D策略优势。

## 3. 数据、时点与指标

- 信号数据：同一交易所永续合约15分钟 OHLCV；成交量 V 为基础币成交量，换手额使用交易所 quote volume，不混用口径。
- 辅助数据：由已收盘15分钟线合成的1小时 OHLCV；独立标记价格序列、资金费率历史与结算时间、交易规则、买卖价差。回测执行优先用1分钟或逐笔数据。
- UTC 对齐15分钟与1小时边界；用户报告用北京时间。t 表示刚收盘的15分钟线；任何信号只能在 t 收盘后产生。1小时只能取当时最近完整的一小时。
- 至少240根完整1小时数据及960根15分钟数据预热。缺失、重复、乱序、非法OHLC、V≤0或指标无效时不开新仓，不补造K线；持仓保护单继续有效。数据恢复并重新满足连续预热后恢复信号。
- EMA(n)：alpha=2/(n+1)，首n根收盘均值为种子。ATR(14)：TR=max(H-L, abs(H-Cprev), abs(L-Cprev))，首14个TR均值初始化，此后Wilder平滑。
- RSI(14)：涨跌幅分别用Wilder平滑；平均跌幅为0且涨幅>0时为100，涨跌均0时为50。
- CLV=(C-L)/(H-L)；下影占比=(min(O,C)-L)/(H-L)。H=L则拒绝该根作为候选或信号。
- RVOL(t)=V[t]/median(V[t-20:t-1])；所有范围均包含两端，历史基准不含当前线。
- 突破位采用固定历史高点，不使用依赖未来右侧K线的分形或会重绘的ZigZag。

## 4. D-R确定性交易规则

### 4.1 状态与优先顺序

状态依次为 IDLE（等待）、WATCH（候选）、PENDING（等待下一根开盘）、LONG（持仓）、COOLDOWN（冷却）。每个品种最多一个候选和一个仓位；同一候选只交易一次，不加仓、不摊平、不反手。

每根先处理持仓风险与退出，再处理冷却，再处理候选失效，最后处理确认或新候选。一根K线不得同时新建候选与确认。已有候选期间忽略新候选；候选失效当根不重新建候选。多个品种同刻触发时BTCUSDT优先，然后ETHUSDT，组合容量不足则放弃后者。

### 4.2 建立候选：先跌得足够，再出现回收

在 IDLE 下，某根 k 收盘同时满足以下全部条件，记作候选锚点 k：

1. C[k-1]<EMA20[k-1]，且 EMA20[k-1]<EMA20[k-5]。
2. A=ATR14[k-1]>0；(max(H[k-12:k-1])-L[k])/A≥2.5。
3. L[k]<min(L[k-8:k-1])，确实刷新近期低点。
4. C[k]>O[k] 或 下影占比[k]≥0.35。
5. CLV[k]≥0.55，且 RVOL[k]≥1.3。

冻结 A、L0=L[k]、N=max(H[k-3:k-1])、失效价 S=L0-0.25A。N为局部结构突破位，不要求等到整段下跌前的高点。WATCH不是买入信号。

### 4.3 候选失效与确认

只允许在 t=k+1…k+6 内确认，即最多等待90分钟。该区间任一根 L[t]<L0-0.10A，候选立即失效；其余情况下第k+6根先允许确认，再到期取消。取消后冷却4根完整15分钟线。

有效候选在 t 收盘同时满足：

1. C[t]>N+0.05A，且 C[t]>EMA9[t]。
2. C[t]>O[t]，CLV[t]≥0.65，RVOL[t]≥1.2。
3. RSI14[t]>RSI14[t-1] 且 RSI14[t]≥35；不强制寻找背离。
4. 0<C[t]-L0≤3.5A，防止反弹过远才追入。
5. 最近完整1小时线 h 不满足“C1h[h]<EMA50_1h[h] 且 EMA20_1h[h]<EMA20_1h[h-3]”这一持续下跌过滤条件。
6. 以 C[t] 为临时入场价时，0.6A≤C[t]-S≤3.0A，且最近完整1小时的 ATR14_1h/C1h≤0.04。

全部成立才记录 D_CONFIRM 并进入 PENDING。强1小时跌势下会错过一部分V形底，这是明确的策略取舍，而非保证抄到最低。

### 4.4 下一根入场

信号后仅在下一根 t+1 开盘执行一次条件检查；不等待更好的价格，不把收盘价当成已经成交。

设 G=O[t+1]，模拟买入成交价 E=G*(1+s)，默认 s=0.0003。实盘以可成交卖一及预估冲击代替 G。满足以下条件才提交市价买单：

- abs(G-C[t])≤0.30A；G>N；G>S；0<E-L0≤3.5A。
- 0.6A≤E-S≤3.0A；(E-S)/E≤0.02。
- 相对价差 (ask-bid)/mid≤0.0005；缺报价时研究回测可显式标记为未验证价差，不可宣称完成执行验证；实盘直接跳过。
- 风控容量、合约最小数量、最小名义价值、逐仓保证金和强平缓冲均合格。

任一失败取消该候选并冷却4根；不将失败订单延后成交。成交立即部署reduce-only止损与止盈，成交后用实际均价重算R与仓位风险；若实际成交导致上限超标则优先减仓，无法建立保护则立即退出并暂停。实盘延迟和拒单必须记录，下一根开盘只是回测近似。

### 4.5 止损、止盈、时间退出

R=E-S，始终以初始价格风险固定，不因移动止损改变定义。

| 项目 | 规则 |
|---|---|
| 初始止损 | S=L0-0.25A，向下取合法tick；按最新成交价触发，市价reduce-only退出；标记价格独立监控强平 |
| 第一止盈 | E+1R，卖出初始数量50% |
| 第二止盈 | E+2R，卖出剩余数量 |
| 第一止盈后 | 从下一根15分钟线开始，止损提高至max(旧止损,E)；这是价格保本，计费后仍可能亏损 |
| 进展不足 | 入场线算第1根；第8根收盘仍未触及TP1则下一根开盘退出全部剩余 |
| 最大持有 | 第16根收盘安排下一根开盘退出全部剩余，最长约4小时，遇延迟记录实际值 |

达到止盈价不意味着挂单必然成交。基线按触发后市价卖出、扣卖方滑点及taker费模拟；止损跳空按更差开盘价成交。仅15分钟OHLC同时碰止损和止盈时采用止损优先；仅同时碰TP1/TP2时按先TP1再TP2。移动止损下一根才生效，避免同线偷用高点。计划时间退出在下一根开盘优先于新信号，同开盘已有止损跳空则按止损退出，不重复成交。成交数量按lot向下取整；无法合法拆分两笔止盈则入场前拒绝交易。

任意平仓后冷却8根完整线。止损不保证最大损失，跳空、插针、流动性不足、系统故障会超出预算。

## 5. 永续合约仓位与账户风控

研究默认逐仓、2倍杠杆上限、USDT线性合约，杠杆只决定保证金占用，不乘到风险预算上。禁用自动追加保证金；不适用于币本位合约的反向盈亏公式。

每单预算 B=当前权益×0.0025。设 f=0.0005 为单边taker费研究假设（不是交易所报价），s=0.0003 为单边滑点初值，b=0.0005 为资金费率风险准备比例。

在止损价和目标价按tick取整后重新计算：

```
S_fill = S*(1-s)
unit_loss = (E-S_fill) + f*(E+S_fill) + b*E
q_risk = B/unit_loss
q_notional = 0.50*权益/E
q_volume = 0.005*上一根已收盘15分钟基础币成交量
q = 按lot向下取整(min(q_risk,q_notional,q_volume,保证金可用数量))
```

0.05%资金费率准备只是仓位缓冲，不替代真实资金费结算。全程按实际结算时间与对应标记价格计算多头资金现金流 -q*mark*rate；正费率支付，负费率收入。部分止盈后按剩余数量计费，不能固定假设每8小时结算。未来实际费率不得用于历史入场筛选。

账户约束：单品种名义价值≤权益50%；组合名义价值≤权益100%；最多2仓；组合在险金额（各仓剩余数量×从各自原入场价到当前保护止损的正向损失，加退出费和资金准备）≤权益0.5%。不得把浮盈当作新增风险额度。

逐仓强平价必须依交易所当前维持保证金档位、费用及保证金余额计算。要求 S-强平价≥2A；不合格则减小杠杆或跳过，不靠追加保证金修正。价格触发止损与标记价格强平可能先后不同，必须分别回放。不能用“2倍杠杆一定不会爆仓”替代验证。[Bybit强平规则](https://www.bybit.global/en/help-center/article/UTA-Trading-Rules-Liquidation-Process)明确区分逐仓和标记价格触发；资金结算参见[Binance资金费说明](https://www.binance.com/en/support/faq/detail/360033525031)。交易所未选定前不启用实盘。

以UTC日初权益为基准，含未实现盈亏、费用及资金费的权益跌幅≥1%时，当即取消待开订单、退出本策略仓位，暂停至下个UTC日。连续3笔净亏损平仓后暂停24小时；不因换币重置。强平、行情断流、保护单缺失或交易规则不可用均暂停新仓并告警。

## 6. D-V视觉量化实验分支

D-V只在D-R确认时决定“通过或拒绝”，不提前猜底、不修改止损、不绕过风险过滤。默认 disabled；无有效模型、超时、证据不符或输入缺失时D-V拒绝交易，不能静默退化并仍标记D-V。D-R独立运行不受模型缺失影响。

输入在 t 收盘截断：96根15分钟K线和96根完整1小时K线，分面图各含OHLC及成交量；数值附带 A、L0、N、CLV、RVOL、RSI与候选索引。图像统一尺寸与配色，各窗口只用自身历史范围缩放。移除截图中的箭头、买卖字样、盈利文字和一切未来蜡烛。不能拿用户这张完整走势直接作为入场时图像。

研究建模方案：用ViT/Swin类图像编码器获得两周期特征，与数值特征融合；另用轻量分类器预测候选交易净盈利概率。模型类型是待比较方案，不宣称某架构已胜出。VLM可生成结构描述和证据索引，不负责精确价格计算。第一阶段不依赖订单流、CVD或持仓量；若以后引入，应有真实历史数据、发布时间和独立消融测试，不能从K线颜色臆测资金流。

监督标签：对所有已满足D-R且可成交的候选，严格按第4、5节模拟到退出；净损益>0为1，否则为0。目标是“这笔既定规则交易净盈利”，不是未来某根会上涨。特征截止t、标签发生在未来，两者隔离。

训练/校准仅使用过去数据。D-V通过要求：校准后概率≥0.60、输入证据验证通过、预期净收益估计>0、模型版本及数据截止时间可追溯。概率0.60是待验证阈值，原始softmax或VLM自报信心不能代替校准概率。预期净收益可用训练期固定概率分箱的平均净R，在验证集选择规则、测试集冻结，不使用测试收益拟合。

输出字段：decision_time、candidate_id、model_version、training_cutoff、input_hash、evidence_bar_indices、structure_label、p_net_positive_calibrated、expected_net_R、grounding_pass、abstain_reason、decision。证据索引必须在输入窗口内，价格关系由OHLCV复核；视觉判断与数值矛盾则拒绝。固定模型、提示词、渲染器和预处理版本并缓存输出。

## 7. 回测与验收计划

1. 至少收集24个月目标交易所历史数据；覆盖牛市、熊市、横盘和高波动，保留退市或不活跃时期的信息，避免只挑表现好的币。数据缺口及缺少标记价格/费率必须单独披露。
2. 时间顺序滚动：训练12个月、验证3个月、测试3个月，向前滚动3个月；末尾另保留连续3个月最终锁定集，不参与任何选择。数据不足则不缩短后冒充同等级验证。
3. 按样本特征起点至标签退出时点整体划分，跨边界样本删除；边界后留出400根15分钟线作隔离缓冲，多品种同步按时间切分。禁止随机拆分重叠K线截图。
4. 首先回测固定D-R，再比较相同执行模型下D-V、数值分类器过滤、取消视觉的消融版本；买入持有只作市场背景对照，并报告暴露差异。
5. 参数只在训练/验证期试验：下跌幅度ATR倍数{2,2.5,3}、确认期限{4,6,8}、成交量门槛候选{1.1,1.3,1.5}。一次只变一个参数，记录尝试次数；其余先冻结，避免全排列挑最佳。
6. 成本用真实账户费率替换假设，并将滑点提高至基线2倍、3倍做压力测试；真实资金费、强平、延迟、拒单和拆单约束纳入结果。
7. 报告交易数、胜率、净期望R、profit factor、最大回撤、日收益Sharpe（24/7按365天）、资金占用、各币种/行情阶段贡献、MAE/MFE、尾部亏损、月度净收益；同时报告区块bootstrap置信区间，避免把重叠信号当独立样本。
8. 研究验收初值：累计样本外≥200笔，扣费净期望>0，净期望95%区块bootstrap下界>0，profit factor≥1.2，最大回撤≤10%，2倍滑点下净期望仍>0。任一未满足就标记未通过，不挑时段隐藏失败。这些门槛是研究治理选择，不保证未来结果。
9. D-V须在匹配测试区间净期望/回撤上有可信增益，同时报告交易覆盖率、Brier分数和校准误差；只减少交易而提高胜率不足以证明更优。
10. 通过后至少30天模拟盘核对信号、成本和执行；不足50笔则延长。实盘还需确定交易所、账户权限、保护单与异常恢复，本交付不包含实盘部署。
