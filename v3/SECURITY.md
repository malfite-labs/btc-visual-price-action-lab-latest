# Security

Do not submit credentials or private account data in issues, pull requests, logs or screenshots. Contact the repository owner privately through a prearranged channel; no disclosure address is configured yet. Rotate exposed credentials at the provider. Deleting a value from a working tree does not remove it from Git history.

This is an experimental simulator, not an assurance of brokerage safety or profitability. Keep external trading credentials separate from market-data and research credentials.
