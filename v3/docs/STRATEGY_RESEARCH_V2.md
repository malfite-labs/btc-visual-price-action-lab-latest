# 策略研究中心 V2（只读）

桌面控制台“策略研究”提供 V3 16 项策略研究，不启动交易引擎、调度或行情连接。D 和 PA 账本直接以 SQLite URI `mode=ro`、`PRAGMA query_only=ON` 读取；其他状态使用现有只读接口。刻意不调用 `/api/v1/d/status`（内部可能重放并写入 D 风控记录）和 `/api/v1/strategy-pool`（PA 扩展读取会申请写事务锁）。各库和接口不是跨源原子快照；持仓中 PA 实时权益未得到可验证估值时显示未知。

A/B/C/E 以 trade_id、成交和 POSITION_CLOSED 审计匹配，采用已持久化的净盈亏。D 以 d_operations 成功响应与成交 ID 校验，G 按 G 的交易 ID、数量和已记录的逐次退出净盈亏，支持分批退出及风险退出；盈亏日历按实际退出时间的北京时间（UTC+08:00）归属。PA-01 至 PA-08 依据执行器每账户单持仓约束以及唯一幂等事件、版本、方向、完整数量和时间验证生命周期；任何缺失、歧义或冲突显示 UNVERIFIED。PA-09/10 如果成交证据没有方向或关联键，保持 UNVERIFIED，不猜测。

账户权益历史只采用 A/B/C/E 已核验完整平仓时，与平仓成交和审计相互匹配的账本 cash_after：此时仓位为空，可作为真实事件时点权益。事件点和窗口手动刷新快照均标注来源；不是连续15分钟序列，也不是回测。图上仅在事件时间与实际权益点重合时标记平仓；缺口超过15分钟不连线。回撤仅覆盖真实观测点，显示起止时间和“覆盖率未知”，不得称完整历史或持仓期间最大回撤。无依据的历史权益和资金费保持未知。

仅有已核验的模拟交易及退出净盈亏参与统计；样本不完整应单独标记，少于30笔提示样本不足，不混用不同市场、币种、资金模型或时间窗口，不将结果自动应用于策略。导出 JSON、CSV、Markdown 到正式项目、旧项目及开发仓库以外的独立目录；文件可能含私人研究账本，不提交 Git。

真实桌面窗口绑定曾返回 owner 不匹配，截图和新版控制台实际点击仍需下次正常打开时验收：正常关闭现有桌面控制台窗口，重新通过桌面入口打开，确认前后端仍为原进程，再点击“策略研究”，检查16项和只读标识；不操作启停按钮。若不能绑定窗口，不强制结束未知进程。
