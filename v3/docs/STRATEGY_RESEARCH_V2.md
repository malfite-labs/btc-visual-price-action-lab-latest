# 策略研究中心 V2（隔离验证版）

桌面控制台“策略研究”打开只读窗口，使用本机 8012 只读 GET 接口，不启动行情连接、调度器或执行器。界面显示 A、B、C、D、E、G、PA-01 至 PA-10，实际注册状态、规则版本和账户值以当前接口为准。G 以自身镜像成交编号及实际净盈亏统计，非独立信号策略；D/E 使用各自接口。PA-09/10 从策略池读取活动状态与各自成交接口。

闭合交易只计算有稳定交易 ID、方向相同、开平数量相等、价格、手续费和时间齐全的记录；重复成交编号、残缺成交及无 ID 的 PA 记录不猜测。已验证样本可能不完整，赢率/PF 仅代表该子样本，少于30笔标记样本不足。成交净额采用已执行价格差及手续费，已记录资金费若不可获取则明确未知；滑点已在价格中，不重复扣除。不能据此比较不同市场、货币、资金模型或不同时段，更不能认定最佳策略。

应用内权益曲线仅使用窗口开启后用户主动刷新时的真实 API 快照，不是完整历史；不写入数据库、不合成丢失时间点，超过15分钟的间隔不连线。没有有效历史权益时回撤不可用。自然日盈亏只汇总带可验证完整开平仓的成交，按北京时间平仓日期归集。用户可选择项目以外目录导出 JSON、CSV 和 Markdown；导出包含账户及交易敏感信息，不提交 Git。

局限：接口不一定提供完整初始资金、历史权益、资金费、成交的历史止盈止损或稳定的 PA 交易 ID；缺失字段不填充。该版本没有可视化截图验收证据，不自动修改策略，也不代替完整交易审计。实际运行账户与研究快照非跨接口原子一致。
