# Contributing

Open an issue with reproduction steps, environment and sanitized evidence. Never post credentials, account databases, raw provider responses or private paths. Explain behavior and run relevant isolated tests. Never invent fills, profits or validation results; distinguish model decisions from rule-driven orders.

Windows process management, reconnect reliability, shadow recovery, time-isolated validation, tests and frontend consistency need work. Changes to formal strategy, risk or simulated execution assumptions require explicit maintainer approval and versioned evidence.
