# 可扩展策略池 JSON v1

策略文件是声明式 JSON 数据，只由白名单解释器读取；上传文件中的脚本、代码和动态依赖一律不执行。

## 文件

- Schema：`strategy-v1.schema.json`（JSON Schema 2020-12；运行时还会执行深度、节点数、周期、数值和风险字段检查）
- 示例：`example-rsi-mean-reversion.json`
- 格式标识：`btc-lab-declarative-strategy/v1`

## 顶层字段

| 字段 | 含义 | 限制 |
|---|---|---|
| `format` | 文件格式版本 | 固定为 `btc-lab-declarative-strategy/v1` |
| `strategy_id` | 策略池唯一 ID | 1–48 个字母、数字、`-`、`_` |
| `version` | 不可覆盖的策略版本 | 1–32 字符；同 ID 下不可重复 |
| `name` | 控制台显示名称 | 1–80 字符 |
| `market` / `timeframe` | 市场及K线周期 | 固定 `BTC/USD`、`15m` |
| `description` | 策略说明 | 最多 1000 字符 |
| `parameters` | 数值参数表 | 最多 32 个有限数值；名称为标识符 |
| `risk` | 账户与风险设置 | 固定 $10,000 USD_RESEARCH、最高5倍名义杠杆、单笔权益风险上限2% |
| `entry` / `exit` | 入场与完整退出表达式 | 受限 AST；不支持用户代码 |

## 表达式

每个表达式对象必须且只能有 `op` 与 `args`。支持逻辑 `and`、`or`、`not`；比较 `gt`、`gte`、`lt`、`lte`、`eq`；交叉 `crosses_above`、`crosses_below`；指标/数据 `sma`、`ema`、`rsi`、`close`、`volume`；参数引用 `param`。指标及K线引用使用整数回看长度 1–200；`close:[1]` 和 `volume:[1]` 表示当前最新已收盘K线，较大数字表示向前回看。`sma`、`ema`、`rsi` 的参数为指标长度。交叉表达式在上一周期与当前周期之间比较两侧值。

运行时最多 256 个表达式节点、递归深度最多 12、逻辑组合最多 16 个子项；拒绝额外字段、未知算子、非有限数值、未定义参数及数据不足。

## 交易语义

- 新策略有各自的模拟账户、持仓、周期水位和成交账本，默认暂停；上传或回测不会启用实时运行。
- 只有共享行情确认来源、BTC/USD币种、报价时间及 freshness 后才能开仓。历史/实时K线缺失、不连续或周期键不匹配时不处理交易。
- 开仓数量调用现有 `backend.domain.calculate_position_size`；费用、滑点、数量精度和最小成交额采用现有 C 研究成本模型。5倍限制名义仓位；仓位按止损距离、费用和滑点计入2%风险上限。
- 停止新开仓不会丢弃持仓。每个持仓保存开仓策略版本、止损、成本模型和订单状态；报价止损由共享报价循环管理，表达式退出在新自然15分钟周期处理。
- 新版本必须通过显式启用；已有仓位仍由开仓版本管理。版本内容按摘要不可覆盖。
- 回测只读已归档连续行情，结果写入独立 `*-backtests.sqlite3` 文件；当前接口最多接受30天范围，不会请求补取行情，也不写实时账户或周期水位。

## 控制台/API

桌面纸盘控制台的“策略池”入口支持添加/上传新版本、验证摘要、比较版本、指定历史版本启用或回滚、暂停/恢复、回测报告及成交明细。启用后先显示“已启用，等待自然周期”；只有周期消费者真实完成处理才显示“运行中”。
